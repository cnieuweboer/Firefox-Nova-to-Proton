Userchrome to change the new Nova theme to look more similar to the previous Proton theme. 

It's not a perfect copy, it's slightly more compact than Proton. And it's not a comprehensive change. Not tested on vertical tabs. And setting pages are largely untouched.

Installation:

Set toolkit.legacyUserProfileCustomizations.stylesheets to true in about:config

Make a "chrome" folder in your Firefox profile folder.

Copy userChrome.css and userContent.css into that chrome folder.
